## [1.0.0] — Flutter Android App & JSON API

### Added
- **JSON API (/api/v1/)** with opaque Bearer token auth and idempotency keys.
- **Flutter Android App** for associates covering Dashboard, Campaigns, Contacts, Wallet, Chat, and Notifications.
- **Server-side cost preview** endpoint for the mobile campaign form.

### Changed
- Service methods (create_campaign, create_invoice, create_schedule) now accept commit=False.
